# 💳 ATM System (C++)

A console-based **ATM System** built using **C++**.

This repository contains the **base ATM application** along with its **first extension**, demonstrating how the system evolves by adding new banking features while maintaining a clean and modular architecture.

The project focuses on practicing **structured programming**, file handling, input validation, and real-world banking operations.

- Secure client login
- Quick Withdraw
- Normal Withdraw
- Deposit
- Balance Inquiry
- Persistent client storage using text files
- Input validation
- Menu-driven console interface
